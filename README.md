# Tyche Picks — Design System

Brand and poster system for **Tyche Picks**, a model-driven sports picks account, and **Tyche Chat** ([tychechat.com](https://tychechat.com)).

**→ [DESIGN.md](DESIGN.md)** is the full system: tokens, logo rules, type, components, poster templates, and the Gemini/Weavy prompt guide. It follows the [awesome-design-md](https://github.com/VoltAgent/awesome-design-md) format, so AI design and coding agents can read it directly.

> Status: draft direction (coin logo + Tyche Chat palette). Not yet confirmed by the client.
